# TechReel AI - Hackathon Demo Guide (2-3 Minutes)

## Pitch Narrative

> *"Students spend hours scrolling short-form videos. Traditional recommenders see a Java meme and recommend 10 more Java memes—trapping the student in a shallow keyword loop. TechReel AI asks: 'What is the student becoming interested in?'"*

---

## 3-Minute Live Demo Script

1. **Open Dashboard (`http://localhost:3000`)**:
   - Highlight tagline: *"Don't stop scrolling. Upgrade what you discover."*
   - Point to the **Before vs After** comparison card.

2. **Current Telemetry**:
   - Show `POV: Your Java code works on the first try 😂`.
   - Explain: High watch time (94%) does *not* mean high learning intent. Intent is 91% Entertainment, 21% Learning.

3. **Click "Run Hackathon Demo"**:
   - The 10-step Agent Activity progress visualizer executes:
     `Observe → Understand → Infer → Plan → Retrieve → Evaluate → Filter → Rank → Explain → Learn`.

4. **Show Interest DNA & Hidden Interest**:
   - TechReel AI synthesized interactions with Java, coding interview jokes, SWE lifestyle, laptop benchmarks, and Git merge conflicts into a latent interest in **Software Engineering (87%)**.

5. **Show Recommendations & Anti-Hype Filtering**:
   - **Top Recommendation**: *How Backend Engineers Think About System Design* (Score: 91/100).
   - **Why NOT These**:
     - ❌ *10 AI Tools that GUARANTEE a $200k Tech Job*: Blocked by Hype Shield (96% Hype, 22% Educational Value).
     - ❌ *Complete Java Tutorial*: Blocked for Content Fatigue & Repetition.
     - ❌ *Advanced Kubernetes eBPF*: Blocked for Difficulty Mismatch.

6. **Interactive Features**:
   - Open **Interest Graph** (`/graph`): Click on *Software Engineering* to explore sub-concepts.
   - Open **Learning Path** (`/learning`): Review the 6-step roadmap from Java syntax to cloud deployment.
   - Click **Take 30s Quiz** on the dashboard to test caching knowledge.
